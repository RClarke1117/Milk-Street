# Milk Street Distillery

Grain-to-glass site for the distillery at 1 Milk Street, Building 1, Branchville, NJ. Built for Clarke Design Studio.

The house makes the liquor. The tasting room is where you meet it on Friday, Saturday, and Sunday.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run qa
```

`npm run build` writes a static site to `out/` (`output: "export"`). That folder is what Cloudflare Pages serves.
